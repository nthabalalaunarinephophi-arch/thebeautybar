Project Overview

The Beauty Bar is a beauty and cosmetics website where customers can view beauty
products, price and add products to a shopping cart.


Website Goals and Objectives

1.Create a simple and attractive beauty website.


2.Allow users to browse products.


3.Allow users to add, remove and change products quantities in the cart.


4.Make the website easy to navigate.


KEY FEATURES

1.Home page


2.Products


3.Shopping cart


4.Add-to-cart button


5.Increase and decrease Products from the cart


6.Delete products from the cart


7.Contact page


8.About page


TIMELINE AND MILESTONES

1.Create website structure, pages and navigation.


2.Add products and shopping cart functionality.


3.Test, improve and finalise the website.

PART 1 DETAILS


Part 1 focuses on creating the basic structure of The Beauty Bar website,including the home page,
